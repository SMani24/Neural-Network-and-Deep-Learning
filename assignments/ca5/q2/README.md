# Q2 notebook versions

Use [Q2.ipynb](Q2.ipynb) as the main notebook. [Q2_colab.ipynb](Q2_colab.ipynb) is the existing Colab variant.

[Q2_recovered_export.ipynb](Q2_recovered_export.ipynb), found as `New Found Files/Q2.ipynb`, has the same code, prose, and decoded output images as the main notebook. Its differences are execution counts, kernel metadata, and image encoding whitespace; it adds no new experiment. The copy is preserved unchanged because its original bytes differ.

Run notebooks from this folder to use the existing `./data` directory.
